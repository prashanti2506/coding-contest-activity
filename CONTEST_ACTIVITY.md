# Coding Contest Activity

## Objective

Participate in a live or virtual coding contest and understand how platform ratings work.

## Tools

- CodeChef or Codeforces — contest participation and rating
- GeeksforGeeks — programming practice

## Preparation

1. Create or log in to a CodeChef or Codeforces account.
2. Open the contest section.
3. Select an upcoming contest or a permitted virtual contest.
4. Register for the contest.
5. Practice basic topics such as arrays, strings, sorting, searching, stacks, and algorithms.
6. Use GeeksforGeeks for additional practice.

## Contest Participation

1. Read each problem statement carefully.
2. Check the input, output, and constraints.
3. Start with problems that are easiest to understand.
4. Implement and test the solution.
5. Submit the solution on the contest platform.
6. Check the verdict after submission.
7. Track the number of attempted and solved problems.
8. Observe the contest ranking and score.

## How Platform Ratings Work

A competitive-programming rating is a numerical value used by a platform to represent a participant's performance in contests. The exact calculation differs between platforms.

Contest performance may involve factors such as:

- Problems solved
- Correctness of submissions
- Time or penalties, where applicable
- Contest rank
- Performance relative to other participants
- Previous rating

The actual rating change should be recorded from the platform's official contest result after participation.

## What I Learned

1. Coding contests involve solving programming problems within a limited time.
2. Careful problem reading is important before coding.
3. Efficient algorithms are important for problems with large input sizes.
4. Contest rankings are based on performance during the contest.
5. Platform ratings provide a way to track competitive-programming performance across contests.
6. Rating systems differ between platforms, so the platform's own contest result should be used when recording the rating change.

## Reflection

This activity provides practical exposure to competitive programming. Unlike ordinary practice, a contest requires time management, problem selection, implementation, testing, and submission under contest conditions. Recording my results and rating after each contest can help me track my progress.
